# SVC-UX-1: Student booking choices

Base: `integration/ux15-modernization` at `4682de3054550abf5242011793497725639548c4`. This Student-facing slice connects the existing flexible Appointment, fixed-slot and Group Session paths without replacing their independent transactions or histories. [Discovery](discovery-and-navigation.md), [eligibility](availability-and-eligibility.md), [recovery](booking-outcome-and-recovery.md), [state](frontend-state-and-safety.md), [accessibility](accessibility-and-responsive.md), [contract assessment](api-contract-assessment.md), [SVC-UX-2 handoff](svc-ux-2-handoff.md), and [validation](validation.md) record details and limits.

Student Home's existing Book appointment entry now explains three choices on the booking page, with links to existing pathways and both histories. Fixed-slot Service selection rechecks the Service and can pass its UUID to group discovery; group discovery can return to fixed slots with that UUID. Flexible booking remains its existing flow and does not claim preselection from another pathway. Context is not authorization or proof that any time or seat is available.

No new staff workspace, booking engine, policy, schema, OpenAPI contract, or deployment is included. Institutional terminology, fixed-only Inventory policy, group prerequisites, discovery preferences and response-loss policy remain open. The fixed-slot API currently maps Inventory-specific failures to generic 500; this UI explains the configured prerequisite and treats that response as uncertain, not a definite refusal. See [contract assessment](api-contract-assessment.md).
