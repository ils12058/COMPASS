# Frontend, accessibility and documents

## Newly executed evidence

All five retained Good Moral browser suites ran on the local optimized Next build in Chromium and WebKit: receipt 37, print 24, correction 5, request 2, assisted 13 = **81 distinct MOCK-UI scenarios per engine**. These simulated API contracts test state/transport/UI behavior; they do not establish backend authority. The separate two REAL-BROWSER Chromium flows are described in [authenticated integration](authenticated-integration.md). Node runs cover 55 distinct receipt/preparation/print/assisted/request/account-cache cases. Production frontend files are unchanged.

Source review confirms stable operation identity per unchanged reviewed intent, initially unchecked confirmation, frozen saved facts, no mutation retry, canonical read reconciliation, cancellation of overlapping reads and account/session/authority ownership. Protected receipt facts and operation IDs are not stored in localStorage/sessionStorage/URLs. Account-cache tests prove protected-query ownership disposal; they are not a live cross-tab security certification.

## PDF and printing preservation

Six new cases (both variants × blank, non-80, cross-variant duplicate) issue historical synthetic certificates while DORMANT, capture all source fields/form/template/applicant/issuer, saved render context and issuance Audit, downgrade empty receipt tables to canonical baseline, upgrade through 0003, import, and compare authorized PDFs before/after. Normalized extracted text/page count are compared; byte identity and pixel-perfect paper equivalence are not claimed. Duplicate identities retain no arbitrary owner; no inspection or reissuance is manufactured. Existing core tests also render actual Chromium PDFs and compare historical HTML/context.

Retained print tests verify issue-confirmation timing, no print on inspection, correct finalized PDF preview, original native `print()` invocation from a user gesture, authorized GSS reprint, Student download, uncertain issuance and PDF retry without reissuance. Print instrumentation is not an OS print dialog or actual paper output. No new print subsystem is added.
