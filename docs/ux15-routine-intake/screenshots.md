# Routine Student Intake visual comparisons

The before images show the integration baseline `f74ee48da7191e1a2a3f0e7ba5bc4e0127655870`; the after images show the production build from this pilot. Each pair uses the same synthetic fixture and viewport. Desktop captures use 1440px; phone captures use 390px. The 320px and 200% text check is recorded in [validation.md](./validation.md).

The sample Student, Counselor, answers, and saved/submitted states are synthetic. No sensitive concern option is selected in these captures. “Other explanation” uses a synthetic scheduling preference.
