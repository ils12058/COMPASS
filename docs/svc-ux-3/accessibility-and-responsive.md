# Accessibility and responsive evidence

SVC-UX-1 synthetic browser cases cover booking choices at narrow phone, tablet, and desktop sizes; page-local fixed discovery; keyboard reachability; fixed-slot confirmation and conflict; Group Session registration and recovery; and 200% CSS text-size behavior. The production browser suites also exercise dialog focus and form retention. Chromium and WebKit results are recorded in [validation](validation.md).

The opt-in real fixed-slot browser transaction ran in Chromium only. No human screen-reader test, native browser zoom check, physical-device test, or institutional accessibility acceptance was completed. Automated layout and keyboard checks do not establish those outcomes. Accessibility assurance is PARTIAL.
