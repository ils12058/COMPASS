## State machine and versions

`REQUESTED → READY_FOR_ISSUANCE → ISSUED`; REQUESTED/READY can become CANCELLED. Any real certificate correction to READY returns to REQUESTED. Issued/cancelled correction is rejected. No PAID, DRY_SEALED, or Cashier-ledger status exists.

The API exposes `actions.request_version = updated_at.isoformat()` and `preparation_version = prepared_at.isoformat()` ([api.py:405–433](https://github.com/ils12058/COMPASS/blob/80b719eb7fbeb86646228b4c013314e8e909876a/be/compass/good_moral/api.py#L405-L433)). Prepare/issue wire payloads require their respective tokens; the service functions allow omission. Correction payload carries **no expected version**, so row locking serializes writes but does not reject a stale editor's intent. Cancellation also has no review token. These are required integration points for future receipt work; timestamps are not a receipt revision identifier.

`work.py` derives preparation work from REQUESTED under operational prepare authority, and issuance work from READY under Counselor issue authority. It contains no separate payment/verification queue ([work.py:34–74](https://github.com/ils12058/COMPASS/blob/80b719eb7fbeb86646228b4c013314e8e909876a/be/compass/good_moral/work.py#L34-L74)). Preserve those queue boundaries when adding blockers.

## Authorization map

Both API and service enforce active role **and** capability, rather than trusting frontend actions. Sources: [service validators](https://github.com/ils12058/COMPASS/blob/80b719eb7fbeb86646228b4c013314e8e909876a/be/compass/good_moral/services.py#L250-L278), [API validators](https://github.com/ils12058/COMPASS/blob/80b719eb7fbeb86646228b4c013314e8e909876a/be/compass/good_moral/api.py#L298-L317), [canonical grants/dependencies](https://github.com/ils12058/COMPASS/blob/80b719eb7fbeb86646228b4c013314e8e909876a/be/compass/accounts/policy.py#L572-L759).

| Actor | Baseline Good Moral authority | Limits to preserve |
| --- | --- | --- |
| Student | `view_self`, `request_self`; owned historical access; eligible self creation and pre-issue self cancellation | No operational receipt write/verification/preparation/issuance; ownership checks remain after lifecycle changes |
| Guidance Services Staff | `view`, `prepare`, `initiate` | Receipt and other clerical corrections only. Cannot correct applicant/college/degree/graduation date; cannot cancel operationally or issue, even with an issue override |

## Eligibility and cross-domain dependencies

F4 uses active Student self-service (or authorized assisted initiation), CURRENT lifecycle, current academic-year submitted Individual Inventory, classified Bachelor's Program/Year Level, current affiliation, canonical semester, and Exit Interview opportunity/submission checks where applicable. F4 rechecks CURRENT lifecycle at issuance. F6 captures a claimed degree/major/graduation date and allows recorded CURRENT/FORMER/GRADUATED Student lifecycle states; it does not independently certify the qualification. Local postgraduate reenrollment must not remove F6 availability. Sources: [eligibility helpers:418–575](https://github.com/ils12058/COMPASS/blob/80b719eb7fbeb86646228b4c013314e8e909876a/be/compass/good_moral/services.py#L418-L575), [creation:735–940](https://github.com/ils12058/COMPASS/blob/80b719eb7fbeb86646228b4c013314e8e909876a/be/compass/good_moral/services.py#L735-L940), [regressions:504–696](https://github.com/ils12058/COMPASS/blob/80b719eb7fbeb86646228b4c013314e8e909876a/be/tests/test_good_moral.py#L504-L696).

No receipt change should bypass or redesign these checks, modify Inventory/Exit Interview submissions, implement Student Academic Records, or add Organization Catalog CRUD. Assisted provenance (`initiation_origin`, `initiated_by`) remains separate from later receipt recorder/verifier/issuer provenance.

## Certificate rendering and printing

Issuance saves form revision, document template key/version, issued timestamp, actual issuer and issuer-name snapshot. F4's UCN form chooses template version 2; older supported saved versions remain renderable. The final renderer requires ISSUED and saved supported provenance, passes saved receipt fields directly, and does **not** invoke preparation/fee/receipt validation on download ([services.py:1401–1439](https://github.com/ils12058/COMPASS/blob/80b719eb7fbeb86646228b4c013314e8e909876a/be/compass/good_moral/services.py#L1401-L1439), [render context:1558–1627](https://github.com/ils12058/COMPASS/blob/80b719eb7fbeb86646228b4c013314e8e909876a/be/compass/good_moral/services.py#L1558-L1627)). Receipt dates/amounts can remain blank in historical PDFs. There is no stored PDF blob promised by this model; output is regenerated from saved facts and supported rendering resources.

The shared renderer uses registered templates and local assets, Playwright Chromium, blocked HTTP(S) subrequests, disabled page JavaScript, and certificate layout settings ([rendering.py:117–210](https://github.com/ils12058/COMPASS/blob/80b719eb7fbeb86646228b4c013314e8e909876a/be/compass/documents/rendering.py#L117-L210)). Active supported form selection is for **new issuance**; existing renderability uses saved supported form identity ([institutional_forms/services.py:75–129](https://github.com/ils12058/COMPASS/blob/80b719eb7fbeb86646228b4c013314e8e909876a/be/compass/institutional_forms/services.py#L75-L129)). The Counselor issue confirmation is followed by issued-PDF print/download controls; PDF retries and print cancellation do not reissue the certificate ([issue section](https://github.com/ils12058/COMPASS/blob/80b719eb7fbeb86646228b4c013314e8e909876a/fe/src/features/good-moral/good-moral-issue-section.tsx#L23-L114), [issued PDF controls](https://github.com/ils12058/COMPASS/blob/80b719eb7fbeb86646228b4c013314e8e909876a/fe/src/features/good-moral/good-moral-issued-pdf.tsx#L49-L108)).
