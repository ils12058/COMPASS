# Authentication shell reflow

Based on `integration/ux15-modernization` at `4bfc1b4185c46cff2a40598f071bad1f2e40168e`. The synthetic [before image](screenshots/before-login-320-200.png) shows the 320px sign-in screen at 200% root text: the brand and heading are clipped and the floating accessibility trigger covers the heading. The shell's `overflow-x-clip` hid the overflow from a document-width-only check. The [after image](screenshots/after-login-320-200.png) shows the same fixture after reflow.

The auth shell now gives Accessibility its own header and the form the remaining page space. Narrow surfaces use viewport-bounded padding; brand items wrap and long headings can break rather than clip. The sign-in heading is shortened to “Sign in”: the nearby brand still identifies COMPASS, and this avoids splitting its name without capping text enlargement. Authentication, MFA, safe return paths, notices and mutation logic are unchanged.

Synthetic browser coverage: signed-out sign-in and initial password request at 320, 390, 768, 1024 and 1440px at 100% and 200% root text, checking document width, interactive bounds, heading/brand text bounds and the accessibility dialog/Escape focus. Chromium and WebKit each passed 20 checks; the final shortened sign-in heading also passed a focused 320px/200% check. The suite was run while the heading-only copy was being refined, so do not treat its earlier wide-screen sign-in runs as a screenshot review of the final wording. Both engines also passed a synthetic 320px/200% mandatory-setup QR check and the existing mandatory authenticator setup and destination-preservation scenario. One earlier WebKit run timed out opening the dialog during simultaneous development compilation; a subsequent full run passed.

These fixtures do not validate real identity, email, MFA, assistive technology, physical devices or institutional UAT. Password confirmation, recovery codes, challenge errors, dark theme, forced colors and other auth states still need dedicated visual review. This is one bounded remediation, not completion of SIMPLIFY-3.
