# Service configuration UX

Services present flexible individual appointments, scheduled individual slots, and Group Sessions
as independent peer pathways. Enabling one pathway does not publish an offering or guarantee an
eligible appointment or seat.

`appointment_booking_enabled` remains the compatibility flag for flexible appointments only.
Duration, cancellation cutoff, and current Inventory settings are described as flexible-booking
settings. Fixed-only Inventory behavior was not expanded.

Appointment provider coverage remains separate from Group Session organizers and facilitators.
Online delivery still does not promise that a video room is ready.
