# SVC-UX-3 handoff

SVC-UX-3 should validate the complete Student and staff lifecycle with real authenticated API and
PostgreSQL fixtures: all three pathways, Service activation versus offering availability,
Counselor self-scope, supervised GSS scope, catalog administration, recent MFA, consequence
reviews, stale and uncertain mutations, Appointment and Group Session history, Inventory
compatibility, provider/facilitator authority, notifications, deep links, and accessibility.

Release gates must include the fixed-slot Inventory error-contract disposition, bounded
Feedback/CSM triage, generated OpenAPI/Orval consistency, typecheck, lint, production build,
focused Node tests, Chromium/WebKit scenarios, backend authorization/lifecycle tests, institutional
terminology/UAT, and hosted CI status. No deployment or automatic merge is part of this handoff.
