# Stakeholder UAT matrix

Execute only in a separately authorized controlled environment with synthetic
accounts/records and safe mailbox destinations. Browser tests here intercept APIs;
backend tests use real domain services/APIs with locmem mail. Neither is a manual
stakeholder acceptance result. Record manual tester/date/environment in Notes when
actually executed. Institutional approval and environment authorization are separate.

Automation references identify supporting code; their actual result/count is in
[validation](validation.md). All manual states below start as **Not executed**,
except the explicit approval gate. Allowed result vocabulary: Automated pass,
Automated fail, Manual pass, Manual fail, Not executed, Blocked, Requires institutional
approval. A future operator may mark Blocked only with the concrete prerequisite.
